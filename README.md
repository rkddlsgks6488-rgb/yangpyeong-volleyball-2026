## 🌟 주요 핵심 기능

### 1. 👥 점수판 팀별 실시간 선수 명단 토글 버튼 (신규!)
- 점수판 홈팀 / 어웨이팀 카드 헤더의 **`[👥 선수 명단]` 버튼**을 클릭하면, 점수판 바로 아래에 각 팀의 등록된 선수 엔트리가 부드럽게 펼쳐집니다.
- 등번호(#번호), 선수 성명, 교직원(👨‍🏫)/학생(🧑‍🎓) 구분 배지, 포지션(세터, 레프트, 센터, 라이트, 리베로), 직책/학년 메모를 경기 진행 중 한눈에 확인 가능합니다.
- 대형 전광판 화면(`scoreboard-display.html`)에서도 단축키 <kbd>R</kbd> 또는 [선수 명단] 버튼으로 출전 라인업을 오버레이할 수 있습니다.

### 2. ⚡ 실시간 스마트 점수판 (Scorekeeper)
- **배구 공식 랠리 포인트제 반영**: 1·2세트 25점, 3세트 15점, 듀스(2점 차 승부) 자동 판정
- **서브권(Service Possession)**: 득점팀으로 자동 이전 및 시각적 배구공 펄스 애니메이션
- **타임아웃(작전타임) 카운트다운**: 세트당 2회 램프 표시 및 30초 타이머 모달 (10초 전 경고음 & 종료 부저음)
- **Web Audio API 내장 사운드**: 브라우저 자체 신디사이저로 휘슬(호각), 경기 종료 부저, 득점음, 팡파레 재생
- **실행 취소(Undo)**: 실수로 올린 점수를 직전 상태로 완벽 복원
- **키보드 단축키 지원**: 현장에서 마우스 없이 키보드만으로 신속한 기록 가능

### 3. 📺 대형 전광판 디스플레이 (Big LED Scoreboard)
- 체육관 빔프로젝터, 대형 LED 전광판, 스마트 TV 전용 고대비 디스플레이 화면 (`scoreboard-display.html`)
- `BroadcastChannel` 기반 **0.01초 실시간 듀얼 스크린 동기화**: 노트북/태블릿에서 심판이 점수를 올리면 대형 화면에 즉각 반영
- <kbd>F11</kbd> 전체화면 모드 최적화

### 4. 🏆 부문별 리그 순위표 및 경기 결과
- **남자부 3팀 풀리그 공식 순위표**:
  - FIVB/V-리그 공식 승점제: 2:0 승리(3점) / 2:1 승리(2점) / 1:2 패배(1점) / 0:2 패배(0점)
  - 1순위 다승 ➔ 2순위 승점 ➔ 3순위 세트 득실률 ➔ 4순위 점수 득실률 순 정렬 및 1위 우승 트로피 표시
- **여자부 리그 결과 카드** (여교직원 1팀 vs 2팀)
- **사제동행 특별 매치 결과 카드** (교직원 연합팀 vs 학생 팀)

### 5. 🖨️ A4 공식 경기 기록지 (Scoresheet) 즉시 인쇄
- 경기별 세트 점수표, 출전 선수 명단, 주심/부심/기록원 서명란 포함
- 인쇄(`Ctrl + P`) 시 웹 UI를 자동으로 숨기고 공식 서식만 출력되는 `@media print` CSS 적용

## ⌨️ 점수판 키보드 단축키

| 단축키 | 기능 설명 |
